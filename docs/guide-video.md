# CSV取得ガイドの実画面動画

2026-11-27に開発者が提供したPC版KOAN録画から作成。原本はリポジトリへ追加しない。

## 公開素材

- public/guides/koan-credit-csv.mp4：約10.2秒、H.264、1120×400、音声なし、約184KB
- public/guides/koan-credit-csv-poster.jpg：編集済み動画の出力画面
- public/guides/koan-credit-csv.ja.vtt：3工程の日本語字幕

成績メニュー→単位修得状況照会→全成績→ファイルに出力する→ファイル出力開始を案内する。OSの保存ダイアログとSyllobusでの取り込みは動画に含めず、文字の手順で補う。

## 個人情報の除去

メニューのみを切り出す前半は上部のユーザー名と下部の通知・予定を除外。後半は出力パネルのみを切り出し、件数の行は不透明な白で覆う。学籍番号を含むファイル名と私用ファイル一覧が映る保存ダイアログは、その出現前で打ち切る。音声と原本のメタデータは除去する。

素材は切り出し・拡大・待ち時間の整理・再生速度の調整を行った実画面であり、画面のボタン名を生成していない。元動画と編集後の連続サンプルを目視し、除外範囲とマスクを確認した。スクリーンショット入力の案内は従来の操作イメージを維持する。

## UI

ネイティブ動画の再生・停止・全画面、インライン再生、字幕、文字での代替手順を提供する。自動再生はしない。取得ガイドを閉じると動画要素を破棄して再生を停止する。
