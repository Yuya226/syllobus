# CSV取得ガイドの実画面動画

2026-11-27に開発者が提供したPC版KOAN録画から作成。原本はリポジトリへ追加しない。

## 公開素材

- public/guides/koan-credit-csv.mp4：約10.2秒、H.264、1120×400、音声なし、約184KB
- public/guides/koan-credit-csv-poster.jpg：編集済み動画の出力画面
- public/guides/koan-credit-csv.ja.vtt：3工程の日本語字幕

成績メニュー→単位修得状況照会→全成績→ファイルに出力する→ファイル出力開始を案内する。OSの保存ダイアログとSyllobusでの取り込みは動画に含めず、文字の手順で補う。

## 個人情報の除去

メニューのみを切り出す前半は上部のユーザー名と下部の通知・予定を除外。後半は出力パネルのみを切り出し、件数の行は不透明な白で覆う。学籍番号を含むファイル名と私用ファイル一覧が映る保存ダイアログは、その出現前で打ち切る。音声と原本のメタデータは除去する。

素材は切り出し・拡大・待ち時間の整理・再生速度の調整を行った実画面であり、画面のボタン名を生成していない。元動画と編集後の連続サンプルを目視し、除外範囲とマスクを確認した。スクリーンショット入力も単位修得状況照会の実画面動画を使用する。

## UI

解析開始カードの左列に大きく配置し、スマートフォンでは縦に並べる。標準操作バー・音量操作は出さず、無音・インラインで自動再生。3回終了したら停止し、タップで再び3回分を開始する。途中のタップは停止・続きから再開。画面外・別タブでは停止し、手動停止していなければ復帰時に再開する。動きを減らす端末設定では自動再生せず、再生操作を待つ。自動再生が拒否された場合もタップで再生できる。字幕相当の短い手順を動画の下に表示し、詳細は取得ガイドに残す。

## 単位修得状況の画像ガイド（2026-11-27）

開発者提供の「画面収録 2026-11-27 1.30.01.mov」から約14秒の無音動画を作成。原本は非公開。メニューと出力条件のパネルだけを切り出し、学生情報が現れる前でカットする。撮影部分の成績表本文は不透明なマスクで覆い、実際の科目名・評語・単位・年度・学期を公開しない。音声・原本のメタデータを除去。公開先は `public/guides/koan-credit-image.mp4` と対応するposter・VTT。

CSV／スクリーンショットの選択に合わせて左列の動画を差し替え、再生回数もリセットする。両方とも3回再生で停止し、タップで停止・再開できる。

画像取込は列見出しを含む画像を最低1枚必要とする。同じPC版の表の続きを同じ列配置で撮影し、最大5枚を一度に送信する。録画中の撮影範囲にかかわらず、案内では列見出し・左右の全列・行全体を含めるよう明記する。スマホでも同じPC表示の表の画像を使えるが、スマホ専用レイアウトの解析には未対応。

## 画像解析の検証

`lib/credit-image.ts` は提供画面で確認したPC表の列配置をNo.と修得年度で位置・倍率補正する。見出しで列配置を検証し、読めない必須セル、行番号の欠落、評語・合否の矛盾は422として再撮影を案内する。科目名からの区分推定、時間割コードの推定、シラバス補完は行わない。画像由来は `university-image` としてCSVと区別し、確認後は同じ卒業判定・同意付き保存へ進む。OCRの区分・年度・学期は確認画面の折りたたみから修正可能。

実データを外部送信せず、架空の3科目を描いた表でGoogle Cloud Visionへの実リクエストを検証した。匿名化ではなく最初から生成した架空データのみのOCR応答を `tests/fixtures/credit-image-ocr.json` に保存。実際の学生の多様な表・専用モバイル表示での精度は未検証のため、取込確認を必須とする。画像の列欠け・行欠けを常に検出できる保証はなく、科目数・内容を元の表と確認する。
