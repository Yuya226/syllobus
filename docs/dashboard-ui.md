# ダッシュボードUI改修（2026-11-26）

既存のGPA計算・卒業要件・超過単位振替・統計公開条件・API・DBは変更せず、表示と操作を整理。

- 先頭にGPA、修得単位、卒業単位の進捗を配置。卒業進捗は確認済み年度の総単位の参考比較であり、卒業可否とは扱わない。未確認条件では設定・要確認を表示。
- 概要／卒業要件／成績分析／履修傾向の4タブ。卒業要件の手動分類状態と比較データはタブ切替時に保持。
- 基本情報・年度別学年と比較条件・データ管理をnative dialogに集約。Escape、閉じるボタン、フォーカス制御を利用。比較条件変更だけでは成績を送信しない。
- 共有保存の同意は初期未選択、保存ボタンは未同意時に無効。削除は既存の確認を維持。デモは保存・削除操作を表示しない。
- 科目別成績は上限高さのあるテーブルに整理。科目名を展開して区分・同順位・評価分布を確認。サンプル不足時は共通の空状態とダッシュ表示を使う。
- 注意事項・統計定義・対応範囲は折りたたみへ。卒業可否を保証しない点とデモ表示は常時表示。
- カード、余白、グラフ配色を統一。スマホでは指標を2段にし、表だけ横スクロール可能にする。

## 検証

- 既存37テスト（GPA、卒業要件、CSV、同意、アクセス制御、集計条件）、Lint、型チェック。
- ブラウザでPC表示と390pxのスマホ表示を確認。スマホのページ幅390px・内容幅390px（横はみ出しなし）。
- 4タブ、成績テーブル、履修傾向、設定の3タブ、Escapeで閉じる、年度変更の卒業要件反映を確認。
- 架空CSV1科目を取り込み、同意を選ばず確定できることと、データ管理の共有保存ボタンが無効であることを確認。実成績は使わず、サーバー保存は実行していない。
- 理学部・数学科・2024年度の条件を設定し、専門2/62・総2/124の既存比較が表示されることを確認。
- デモのGPA2.82・19単位、卒業総単位の参考比較19/130を確認。デモ内データ管理に共有保存操作がないことを確認。
- 設定タブの高さ変化時にdialogが意図せず閉じる不具合を修正。背景クリック終了をなくし、明示的な閉じる操作とEscapeを使用。

## 2026-11-26: 卒業要件を起点にする

- 初期表示を卒業要件に変更。概要タブと「次に確認すること」の重複リンクを削除し、成績グラフは成績分析へ集約。
- 卒業単位の進捗を先頭へ。未確認事項・手動確認の説明は卒業要件の下部で折りたたむ。個別の未確認表示や参考計算の区別は維持。
- 比較集計を1回自動取得して2タブで共用。デモでは取得しない。取得エラー時のみ再試行を表示。
- 入力済み入学年度の同期集計を優先。比較学期は明示設定、なければ最新の取込学期を利用する。学年・全件収録は推定しない。「取込分」と全修得数を区別する。
- 同期集計も20セッション未満・単一値を非公開とし、全件確認済み・時点の整合する投稿のみ使用。新しい同意なしに成績を自動送信しない。
- 条件の自動選択と同期集計の除外・少数保護をテスト追加。
