# 公開受入チェック（2026-11-26）

## 完了した実装

- 単位修得状況CSVを主入力にし、大学の区分・単位数・修得年度・学期を使用。個人識別項目は取り込まない。
- 重要指標を先頭に配置、4タブと設定ダイアログへ整理。科目比較はテーブル、少数標本は共通の空状態。
- 共有保存の同意は初期未選択。デモの架空成績をDB・統計へ送信しない。
- Cloudflare Workers + D1へ公開。公開APIの保存・復元・削除、他セッションからの拒否を確認済み。
- 経済2019〜2024／2025以降の参考計算、理学部2024〜2026の大区分比較、他学部の出典付き参考表。未確認の年度・必修・読替を卒業可能とは判定しない。
- 相対評価は同順位の範囲と標本数を表示。20セッション以上、少数評語5件未満等の公開制限を回帰試験済み。
- 依存パッケージ監査0件。middlewareからproxyへの変更はOpenNextの実験対応を理由に保留。
- 画像の学期が未記載ならnullを保持。画像の重複排除は同一行のみとし、異なる学期・評語は確認画面に残す。推定単位や重複確認の注意を表示。

## 新環境のみで運用する方針（開発者決定）

旧Supabaseの復旧・エクスポート・データ移行は実施せず、公開の前提条件から外す。すでに独立して稼働しているCloudflare Workers + D1を正式な運用先とし、過去の利用者には単位修得CSVを再取り込みしてもらう。サーバー保存・統計提供には新たに明示的な同意を得る。

旧DBの実際の件数・内容は取得できていない。コード上の保存対象は、従来の投稿成績（grade_submissions）、単位修得CSVの成績・比較条件（credit_snapshots）、科目照合用のシラバス情報（subjects）。各テーブルが旧DBに実在する、あるいはデータが入っていると確認したわけではない。

単位修得CSVは必要な区分・単位数・学期を持つため、旧シラバスDBの復旧を待たずに利用できる。シラバス照合を使う従来CSV・画像入力は補助対応とし、未照合・推定を明示する。統計は新環境の同意済み投稿が公開条件を満たしてから表示する。

本番設定はDATABASE_PROVIDER=d1で旧Supabaseへ接続しない。新環境のデータや利用者のブラウザ内成績は初期化しない。旧Supabaseの削除・契約解除は今回の変更に含めない。

### 1. スマートフォン実機の受入

2026-11-26：利用者へ依頼した簡易手順（データ取扱い確認→CSV選択→成績一覧→共有保存せず確定）について、Mac・Google Chromeで「できました」、iPhone・Chromeで「おっけ」との報告を受領。通常のCSV取り込みは両環境で確認済み。以下の詳細項目すべての合格へ拡大解釈しない。

https://syllobus.com/dashboard で以下を実施し、端末／ブラウザ／結果を記録する。

1. データの取扱いを読み、単位修得CSVを選択する。
2. 科目数・単位数・評語・修得学期が元CSVと一致するか確認する。
3. 共有保存の同意は選ばず確定する。
4. 概要／卒業要件／成績分析／履修傾向を開く。
5. 設定を開き、学部・入学年度、閉じる操作、表の横スクロールを確認する。
6. 画像入力も利用する場合は氏名・学籍番号を除いた画像で、OCR送信の説明に同意して確認する。画像はGoogle Cloud Visionへ送信される。

ブラウザの390px表示テストは実機Safari／Androidのファイル選択を代替しない。操作ツールのファイル選択停止も実機成功とは扱わない。
