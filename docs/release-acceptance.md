- 重要指標を先頭に配置、4タブと設定ダイアログへ整理。科目比較はテーブル、少数標本は共通の空状態。

- Cloudflare Workers + D1へ公開。公開APIの保存・復元・削除、他セッションからの拒否を確認済み。
- 経済2019〜2024／2025以降の参考計算、理学部2024〜2026の大区分比較、他学部の出典付き参考表。未確認の年度・必修・読替を卒業可能とは判定しない。

- 依存パッケージ監査0件。middlewareからproxyへの変更はOpenNextの実験対応を理由に保留。
- 画像の学期が未記載ならnullを保持。画像の重複排除は同一行のみとし、異なる学期・評語は確認画面に残す。推定単位や重複確認の注意を表示。

## 開発者の確認が必要な3項目

### 今回の検証結果

- 回帰テスト38件、Lint、型チェック、OpenNext本番ビルド成功。
- `node scripts/smoke-ocr.mjs https://syllobus.com`：生成した架空画像を実際のGoogle Cloud Visionで解析。2科目のコード・年度・A/B評語、学期不明の保持、不正PNGの400拒否を確認。保存APIは呼び出していない。これは実際のKOAN画像すべての読取精度を保証する試験ではない。
- `node scripts/smoke-cloudflare.mjs https://syllobus.com`：認証、保存、復元、他セッションの読取／書込／削除の拒否、少数集計抑制、検証レコードの削除を確認。
- ブラウザで同意前のアップロード無効化を確認。ファイル選択ツールが停止したため、この回のブラウザ経由の不正CSV→再試行は未検証。CSVの解析・拒否は回帰試験済み。

### 1. 旧Supabaseの状態

対象プロジェクトは `cncgjzyozrfjslypneoo`。DashboardでActive／Restoring等の状態、Table Editorでsubjects・grade_submissions・credit_snapshotsが見えるか確認する。

- Restoringが続く：管理画面のContact supportから復旧を依頼する。
- Activeでテーブルが見える：テーブルのスキーマ名を確認し、状態と存在の有無だけを共有する。
- テーブルが見えない：バックアップ・復旧状況と接続先プロジェクトを確認する。空データを新規作成して復旧済みとは扱わない。

秘密鍵、接続文字列、実成績の内容はチャットへ貼らない。読み取りAPIは3テーブル404・公開パス0件のため、現時点では旧データをエクスポートできない。Cloudflare版は独立して稼働する。

### 2. スマートフォン実機の受入

https://syllobus.com/dashboard で以下を実施し、端末／ブラウザ／結果を記録する。

1. データの取扱いを読み、単位修得CSVを選択する。
2. 科目数・単位数・評語・修得学期が元CSVと一致するか確認する。
3. 共有保存の同意は選ばず確定する。
4. 概要／卒業要件／成績分析／履修傾向を開く。
5. 設定を開き、学部・入学年度、閉じる操作、表の横スクロールを確認する。
6. 画像入力も利用する場合は氏名・学籍番号を除いた画像で、OCR送信の説明に同意して確認する。画像はGoogle Cloud Visionへ送信される。

ブラウザの390px表示テストは実機Safari／Androidのファイル選択を代替しない。操作ツールのファイル選択停止も実機成功とは扱わない。

### 3. KOANの新CSV取得手順

単位修得状況照会の出力ボタンの正確な名称、出力前に必要な選択操作、PC／スマホのどちらかを確認する。チュートリアルはこの情報を反映して確定する。掲載用画像・動画は任意で、氏名・学籍番号・実成績・他のタブ等を含めない。元の個人スクリーンショットは公開しない。

## 今回の公開で保証しない範囲

- 全学科・全入学年度の完全な卒業可否判定。必修・外国語の内訳・読替等は公式便覧で確認する。[調査範囲](requirements-research.md)を参照。
- 投稿が集まる前の実データによる統計検証。合成標本はテスト内でのみ使用し、本番統計へ蓄積しない。
- 旧データの完全移行。復旧後のエクスポート、同意・スキーマ・新DBでの更新／削除との競合確認が必要。

この3項目を未確認のまま「全タスク完了」とは記録しない。現在の制限を明示したサンプルデータによるデモと、全機能の完全対応は区別する。
